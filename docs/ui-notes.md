0.3增加了常用/全部节点切换、示例搜索、插件源码管理和文档表格/代码/链接显示。窄屏保留插件图标入口，身份证低频参数折叠。下文还保留0.2排版改动及当时验证记录。

这次调整集中在本地 Web 工作台的可读性和完整使用流程。Python 插件接口、流程 JSON 和处理算法保持兼容。

## 字体与层级

使用系统字体栈 Segoe UI、Microsoft YaHei UI、PingFang SC、system-ui，不依赖外部字体服务或联网下载。正文字号以 14px 为基准，表单与操作文字 13px，辅助说明通常 12px，节点标题 16px。较小字号仅用于类型标记等短标签。

降低淡蓝文字的使用比例，正文使用深灰，辅助信息使用可读的灰色，蓝色留给当前操作与选中状态。字号、行高、输入框高度和表格行距统一调整。图标按输入、字段、文本、校验、计算等功能区分，移除了处理模块统一使用的 ƒ 符号。

基础组件样式在 frontend/src/styles.css；新工作区与编辑器细节在 frontend/src/home.css。

## 工作区与编辑器

首页集中显示继续编辑、空白流程、示例、已保存流程和数据文件。统计数量全部来自当前工作区。选择文件会建立一条包含输入节点的新流程；如果当前有未保存修改，先通过页面内确认框选择是否切换。

工作区与编辑器之间切换不清空当前画布。首页支持搜索已保存流程，右上方仍保留设置和文档入口。实现位于 WorkspaceHome.tsx，业务回调由 App.tsx 提供。

## 表单与画布

presentation.js 只处理显示名称：参数键和选项翻译成中文，保存的仍是原始机器键和值。第三方插件的未知参数原样显示，不要求插件修改接口。编码、分隔符、换行和诊断信息集中到“更多选项”，常用配置优先展示。

draftProblems 提供缺少输入连接、缺少必填参数和插件未加载的提示。它只是草稿辅助检查，实际运行仍由后端 Pipeline.plan 和插件进行权威校验。

默认以流程开头几个节点为阅读范围，避免长流程被整体缩到不可读。查看完整流程可切换全图视角；缩放与导航按钮放在画布标题栏，缩略图按需打开，减少对节点的遮挡。宽度不超过 1100px 时配置面板默认收起，选择节点后通过侧面面板编辑。

## 结果与状态

预览区顶部有可拖动的分隔条，也可以聚焦后用上下方向键调整。高度偏好保存在浏览器中；收起后点击任意结果标签重新展开。每次新任务会自动展开预览区。

运行结束后保留摘要，包括完成数量、节点执行耗时之和、生成文件数量和错误信息。调整参数后提示结果来自旧配置。字段建议不会优先使用已经过期的运行表头。

useServiceStatus 每 8 秒检查本地服务，单次请求超时为 3.5 秒；连接失败显示提示并禁用运行与保存。检测到服务恢复后获取新的会话 token，保留当前编辑中的画布。0.3还会在后端明确以“会话已变化”403拒绝、尚未执行写入时，获取新令牌并仅重试一次；其它拒绝或失败不重试。

## 对话框与保存

useConfirmation 替换浏览器原生 confirm，统一切换与删除提示。对话框限制 Tab 焦点范围，Escape 关闭，关闭后恢复焦点；删除确认默认聚焦取消按钮。删除流程会明确说明输入和导出文件保留。

保存通过互斥标记避免连续触发重复请求；正在保存或运行时不能切换到另一条流程。已有的项目修订号检查继续由后端执行。

## 验证与阅读入口

frontend/tests/model.test.mjs 检查流程契约，presentation.test.mjs 检查显示名回退与草稿提示。构建包含 TypeScript 检查。浏览器操作覆盖保存、模板切换、确认取消、键盘焦点循环、节点配置、结果收起/展开、方向键调整高度和真实文件导出。

已检查常规桌面窗口及 900px、390px 宽度；窄屏工具栏改为带可访问名称的图标按钮。另在独立测试工作区停止并重启服务，验证断开提示、禁用运行、恢复会话 token 和再次生成 4 份导出文件。回归结果为 36 项 Python 测试、8 项前端测试通过，生产构建与格式检查通过。
