# 后续方向

当前0.5有56个内置节点。首次三道公开比赛题计算结果与出题人公布的flag一致，见 [首次实测](real-ctf.md)；另有浙江/羊城杯原附件的完整处理、独立规则核对与正式提交文件，见 [第二批实测](contest-round2.md)。字典候选、人工修订、逐格评分和CSV/XLSX教学样例见 [纠错文档](correction.md)。

下面是尚未实现的候选项，不代表已有功能或固定排期：

- 题目规则：统一社会信用代码、带版本的历史行政区划字典、比赛专用答案评分、完整混合敏感字段分类。
- 格式与修复：跨字段冗余推断、更多字典约束、表格中就地审核候选。已有近似候选与可导入的人工清单。
- 输入适配：SQL dump、数据库查询、HTTP以外的PCAP协议、TLS解密，按真实题目再做。
- 大数据：磁盘表格存储、流式处理、历史压缩、可控内存预算。
- 任务：进程隔离、强制取消、持久运行历史、跨文件事务或失败恢复策略。
- 前端：App 状态逐步拆 hooks、连线就地插入节点、多选批量操作、更多专用参数编辑器。
- 插件：接口兼容性检查、依赖声明、更新版本比较。插件当前仍是可信代码，无沙箱。
- 工程：安装包资源打包、版本迁移、更多带标准答案的真实CSV/XLSX纠错回归、无 Python 环境的桌面分发。

目前优先拿真实题目验证通用节点是否够用，再决定加哪些插件。
