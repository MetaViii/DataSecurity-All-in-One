# DataSecurity all in one

针对CTF的数据安全类型题目做的数据流图形化工具

覆盖常用的各种数据处理要求

## 设计思路

基于python作为处理后端的WebUI

~~我也万物皆插件有感觉吗~~

初步的想法是这样，由于数据安全的处理要求比较杂，输入的格式也比较多样，我把整个项目分成了三个模块来做

```
输入层->数据处理层->输出层(一般都为csv)
```

### 输入层

输入层需要兼容多种文件格式，例如`.log`、`.sql`、`.csv`、`.pcapng`

接着将其转存为JSON/直接载入数据库

再利用数据处理层

### 数据处理层

使用plugins库中的各种脚本来做各种需求，使用模块指定对数据的处理动作，模块中细化出不同库进行指定某方向的需求(比如身份证算法是否合规、名字长度是否在区间内、筛选指定性别的样本)

目前整理出来大致有这几个模块

#### classification

对数据进行分类，比如说分类密码强度之类的

侧重对已有数据的分类

#### Filter(主要模块)

对数据中某些元素进行按要求的筛选(不需要的进行丢弃,包括长度，格式要求，算法要求)

可以进行多层筛选，单层的筛选支持多属性的条件指定

侧重对已有数据的提取、丢弃

#### Sort

主要对数据进行统计/排序

侧重对已有数据的排序

#### 2E(Encode、Encrypt)

对数据进行编码解码/使用指定算法进行加密

### 输出层

输出层一般都是`csv`，也可以直接以json的形式输出





然后一层算作一个node，通过多个node的连接将数据层层处理最后到达输出层

## 架构

前端使用React，后端使用python

在Web页面通过类似流程图的方法来处理数据

并且支持sql文件直接建库(其实UI还是最后的，把主要核心功能做出来就ok)
